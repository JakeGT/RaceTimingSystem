# Security policy

Please **don't open a public issue** for security problems. Report them privately through GitHub's [private vulnerability reporting](https://github.com/JakeGT/RaceTimingSystem/security/advisories/new) instead.

You should hear back within a week. This is a volunteer project, so please allow reasonable time for a fix before disclosing publicly.

The code on the `legacy` tag (the original university prototype) is unmaintained and gets no security fixes. Don't deploy it.
