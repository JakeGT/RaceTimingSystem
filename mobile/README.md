# mobile/

The phone capture app: it runs bib detection and recognition on the device, keeps an offline outbox, and pairs by QR code.

**Not started yet.** The stack (React Native + VisionCamera, native, or Flutter) will be chosen by the Phase 3 spike, which measures fps, battery and heat on real phones. See [the rebuild plan](../docs/REBUILD_PLAN.md) §6–§7 and [ADR 0001](../docs/decisions/0001-licence-and-detector.md) for detector constraints.
