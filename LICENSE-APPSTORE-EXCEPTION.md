# Additional permission for app-store distribution (DRAFT)

> **Status: DRAFT. Not yet part of this project's licence terms.** This needs reviewing by someone qualified before the first public release of the mobile app ([ADR 0001](docs/decisions/0001-licence-and-detector.md), rebuild plan Phase 0). Until then, the project is licensed under the AGPL-3.0-or-later alone.

## Proposed text

Additional permission under section 7 of the GNU Affero General Public License, version 3:

The copyright holders of the mobile application in this repository (the contents of the `mobile/` directory, and any other part of this repository compiled into that application) give you permission to convey that application in object code form through an application store (for example, the Apple App Store or Google Play) whose terms of service or usage rules impose further restrictions on recipients, provided that:

1. the Corresponding Source of the application is offered to every recipient under the terms of this License, at no charge, by a means outside that store, such as a public source repository linked from the store listing; and
2. apart from restrictions imposed by the store itself, you place no further restrictions on recipients' exercise of the rights granted under this License.

This permission covers only code whose copyright holders have granted it by contributing to this repository under its licence terms. It doesn't extend to third-party components, which is why shipped third-party components must be under permissive licences ([ADR 0001](docs/decisions/0001-licence-and-detector.md)).
